# Garden Manager V1.2.0

Bản V1.2.0 nâng cấp quy tắc điều hướng sau khi lưu dữ liệu.

- Lưu cây/chậu/vị trí/nhật ký/sự vụ/kho/khu: đóng toàn bộ popup của tác vụ và trở về ngay module nguồn.
- Nút Hủy / Quay lại vẫn điều hướng theo từng tầng khi chưa lưu.
- Giữ nguyên sơ đồ nền gạch 50 × 50 cm, gốc tọa độ góc trên-phải, nhấn giữ 1 giây và các chức năng của R10.
- Tiêu đề ứng dụng hiển thị rõ `V1.2.0 · Save-to-Module Navigation`.
- PWA cache: `garden-manager-v1.2.0`.
